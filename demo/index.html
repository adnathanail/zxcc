zxcc — <zx-diagram> demo

Each section below sets the diagram property on a <zx-diagram> custom element. Drag nodes to see the D3 layout respond.

1. Identity wire

One input, one output, one edge.

2. Single Z spider with a phase

Z spider at π/2 between one input and one output.

3. Bell-state preparation (Z ⊗ Z with CNOT-like connection)

Two Z spiders sharing an edge, plus a Hadamard on one leg.

4. Two-spider fusion candidate

Two adjacent Z spiders — the target of the spider-fusion rule.

5. Parallel edges

Two spiders connected by two parallel wires (drawn as bezier arcs).

6. Symbolic phase label

The labels field overrides the spider's phase text.

7. Render error path

A malformed diagram (nodes missing) triggers the error UI with a Retry button.

Algebraic layout (pre-positioned + boxes)

Setting col/qubit on any node skips the BFS auto-layout — every node is expected to carry both. The boxes field draws translucent rectangles behind subtrees: orange dashed for stack, blue solid for compose. These demos mirror what LeanSpider's ZX n m algebraic term walker emits.

8. spider Z 2 2 (π/2)

A single 2-in-2-out Z spider, centred at q = 0.5. No boxes — leaves emit none.

9. stack (spider Z 1 1 α) (spider X 1 1 β)

Two spiders stacked vertically. One orange dashed stack box covers both body nodes.

10. compose (spider Z 1 2 0) (spider Z 2 1 0)

Spider-fusion candidate: two Z spiders composed by two parallel edges, wrapped in one blue compose box.

11. Nested: compose (stack (Z 1 1) (Z 1 1)) (X 2 1 π/2)

Inner stack box (orange) sits inside the outer compose box (blue). Boxes are sorted largest-first so outer paints behind inner.
