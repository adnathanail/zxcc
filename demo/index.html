zxcc — <zx-diagram> demo

Each section below sets the diagram property on a <zx-diagram> custom element. Drag nodes to see the D3 layout respond.

1. Identity wire

One input, one output, one edge.

2. Single Z spider with a phase

Z spider at π/2 between one input and one output.

3. Bell-state preparation (Z ⊗ Z with CNOT-like connection)

Two Z spiders sharing an edge, plus a Hadamard on one leg.

4. Two-spider fusion candidate

Two adjacent Z spiders — the target of the spider-fusion rule.

5. Parallel edges

Two spiders connected by two parallel wires (drawn as bezier arcs).

6. Symbolic phase label

The labels field overrides the spider's phase text.

7. Render error path

A malformed diagram (nodes missing) triggers the error UI with a Retry button.
